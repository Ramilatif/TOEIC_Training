# Les formes des conditionnels

## Tableau récapitulatif

| Type | Proposition en *if* | Proposition principale | Exemple |
| --- | --- | --- | --- |
| **0 — Vérité générale** | présent | présent | *If you heat ice, it **melts**.* |
| **1 — Réel / probable** | présent | will + base | *If it **rains**, we **will cancel**.* |
| **2 — Irréel du présent** | prétérit | would + base | *If I **had** more time, I **would help**.* |
| **3 — Irréel du passé** | had + participe | would have + participe | *If we **had left** earlier, we **would have arrived**.* |
| **Mixte** | had + participe | would + base | *If he **had studied**, he **would be** a manager now.* |

## Règles de forme

- **Jamais *will* ni *would* dans la proposition en *if*** : *If I **have** time* (pas *will have*).
- **Be au type 2** : *If I **were** you*, (were pour tous les sujets, en style soigné).
- **Inversion formelle** (très fréquente au TOEIC) :
  - *If you need help* → ***Should you need** help*
  - *If we had known* → ***Had we known***
  - *If I were you* → ***Were I** you*

## Autres mots pour poser une condition

*unless* (= if … not), *provided that / as long as* (à condition que), *in case* (au cas où), *otherwise* (sinon).

## Pièges des francophones

- **Le français emploie le futur ou le conditionnel après *si*, l'anglais jamais** : *If you **come*** (pas *will come*).
- **Type 3** : le participe passé est indispensable : *would have **arrived***.
- **Should** en début de phrase = *if*, pas un conseil.

# Conditional forms

## Summary table

| Type | *if* clause | Main clause | Example |
| --- | --- | --- | --- |
| **0 — General truth** | present | present | *If you heat ice, it **melts**.* |
| **1 — Real / likely** | present | will + base | *If it **rains**, we **will cancel**.* |
| **2 — Unreal present** | past | would + base | *If I **had** more time, I **would help**.* |
| **3 — Unreal past** | had + participle | would have + participle | *If we **had left** earlier, we **would have arrived**.* |
| **Mixed** | had + participle | would + base | *If he **had studied**, he **would be** a manager now.* |

## Form rules

- **Never *will* or *would* in the *if* clause**: *If I **have** time* (not *will have*).
- **Be in type 2**: *If I **were** you*, (were for every subject, in careful style).
- **Formal inversion** (very frequent on the TOEIC):
  - *If you need help* → ***Should you need** help*
  - *If we had known* → ***Had we known***
  - *If I were you* → ***Were I** you*

## Other words that set a condition

*unless* (= if … not), *provided that / as long as* (on condition that), *in case* (just in case), *otherwise* (or else).

## Traps for French speakers

- **French uses the future or conditional after *si*, English never does**: *If you **come*** (not *will come*).
- **Type 3**: the past participle is essential: *would have **arrived***.
- **Should** at the start of a sentence = *if*, not advice.
