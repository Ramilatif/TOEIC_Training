# Gérondif et infinitif : cas avancés

## 1. Verbes qui changent de sens selon la forme

| Verbe | + gérondif (-ing) | + infinitif (to) |
| --- | --- | --- |
| **remember** | se rappeler **avoir fait** | penser **à faire** |
| **forget** | oublier **avoir fait** | oublier **de faire** |
| **stop** | **cesser de** faire | s'arrêter **pour** faire |
| **regret** | regretter **d'avoir** fait | regretter **de devoir** (annonce formelle) |
| **try** | **essayer** (tester) | **tenter** (faire un effort) |
| **go on** | **continuer** la même chose | **enchaîner** avec autre chose |
| **mean** | **impliquer** | **avoir l'intention de** |

- *I remember **sending** the file.* (je me rappelle l'avoir envoyé)
- *Remember **to send** the file.* (n'oubliez pas de l'envoyer)
- *We regret **to inform** you…* (formule de lettre formelle)
- *He stopped **to check** his email.* (il s'est arrêté pour consulter ses mails)

## 2. Après une préposition : toujours le gérondif

*interested **in** working*, *capable **of** managing*, *without **asking***, *by **investing***, *look forward **to** hearing*, *be used **to** working*.

## 3. be used to / get used to / used to

| Forme | Sens | Exemple |
| --- | --- | --- |
| **be used to** + -ing | être habitué à | *I **am used to working** under pressure.* |
| **get used to** + -ing | s'habituer à | *She is **getting used to working** nights.* |
| **used to** + base | avait l'habitude de (passé révolu) | *We **used to print** everything.* |

## 4. Gérondif passif et parfait

- *She hates **being kept** waiting.* (gérondif passif)
- *He denied **having seen** the memo.* (gérondif parfait = antérieur)
- *I appreciate **your helping** us.* (sujet du gérondif au possessif, style formel)

## 5. Infinitif parfait et passif

- *To **have completed** the project early was a real achievement.*
- *The report is **to be submitted** by Friday.*
- *The plan appears **to have worked**.*

## 6. Constructions utiles

| Expression | Suivi de | Exemple |
| --- | --- | --- |
| **It is no use / no good / worth** | -ing | *It is **no use** complaining.* · *It is **worth** trying.* |
| **have difficulty / trouble / a hard time** | -ing | *We **have difficulty** finding staff.* |
| **spend / waste time** | -ing | *They **spent** hours **revising** the file.* |
| **too … to / enough … to** | infinitif | *The room is **too small to** hold us.* |
| **be about to / be likely to / be bound to** | infinitif | *The meeting **is about to** start.* |

## Pièges

- **« Look forward to + base »** est faux : *look forward to **seeing*** (to = préposition).
- **suggest + -ing** (ou *that* + sujet + base) : *I suggest **meeting*** (pas *to meet*).
- **enjoy / avoid / consider / postpone / delay** : toujours le gérondif.
- **decide / agree / refuse / manage / afford** : toujours l'infinitif.

# Gerund and infinitive: advanced cases

## 1. Verbs that change meaning with the form

| Verb | + gerund (-ing) | + infinitive (to) |
| --- | --- | --- |
| **remember** | recall **having done** | remember **to do** |
| **forget** | forget **having done** | forget **to do** |
| **stop** | **cease** doing | stop **in order to** do |
| **regret** | regret **having** done | regret **having to** (formal announcement) |
| **try** | **experiment** (test) | **attempt** (make an effort) |
| **go on** | **continue** the same thing | **move on** to something else |
| **mean** | **involve** | **intend** |

- *I remember **sending** the file.* (I recall sending it)
- *Remember **to send** the file.* (don't forget to send it)
- *We regret **to inform** you…* (formal letter phrase)
- *He stopped **to check** his email.* (he stopped in order to check)

## 2. After a preposition: always the gerund

*interested **in** working*, *capable **of** managing*, *without **asking***, *by **investing***, *look forward **to** hearing*, *be used **to** working*.

## 3. be used to / get used to / used to

| Form | Meaning | Example |
| --- | --- | --- |
| **be used to** + -ing | be accustomed to | *I **am used to working** under pressure.* |
| **get used to** + -ing | become accustomed to | *She is **getting used to working** nights.* |
| **used to** + base | did regularly (finished past) | *We **used to print** everything.* |

## 4. Passive and perfect gerund

- *She hates **being kept** waiting.* (passive gerund)
- *He denied **having seen** the memo.* (perfect gerund = earlier)
- *I appreciate **your helping** us.* (possessive subject of the gerund, formal)

## 5. Perfect and passive infinitive

- *To **have completed** the project early was a real achievement.*
- *The report is **to be submitted** by Friday.*
- *The plan appears **to have worked**.*

## 6. Useful constructions

| Expression | Followed by | Example |
| --- | --- | --- |
| **It is no use / no good / worth** | -ing | *It is **no use** complaining.* · *It is **worth** trying.* |
| **have difficulty / trouble / a hard time** | -ing | *We **have difficulty** finding staff.* |
| **spend / waste time** | -ing | *They **spent** hours **revising** the file.* |
| **too … to / enough … to** | infinitive | *The room is **too small to** hold us.* |
| **be about to / be likely to / be bound to** | infinitive | *The meeting **is about to** start.* |

## Traps

- **"Look forward to + base" is wrong**: *look forward to **seeing*** (to = preposition).
- **suggest + -ing** (or *that* + subject + base): *I suggest **meeting*** (not *to meet*).
- **enjoy / avoid / consider / postpone / delay**: always the gerund.
- **decide / agree / refuse / manage / afford**: always the infinitive.
