# Les modaux

Un modal est suivi du **verbe à l'infinitif sans *to*** et ne prend jamais de *-s* ni *-ed*.

## Sens principaux

| Modal | Sens | Exemple |
| --- | --- | --- |
| **can / could** | capacité, possibilité, demande polie | **Could** you send the file? |
| **may / might** | permission, possibilité | The shipment **may** arrive late. |
| **must** | obligation forte, déduction | Employees **must** wear badges. |
| **have to** | obligation externe | I **have to** renew my passport. |
| **should / ought to** | conseil, obligation faible | You **should** back up your files. |
| **will / would** | futur, offre, hypothèse | **Would** you like some tea? |
| **shall** | proposition (I/we) | **Shall** we start? |

## Formes à connaître

- **Passé / perfectif** : modal + **have** + participe passé : *The report **should have been** sent.*
- **Passif** : modal + **be** + participe passé : *All forms **must be submitted**.*
- **Négation** : *must not* (interdit) ≠ *do not have to* (pas nécessaire).

## Pièges

1. **Pas de *to* après un modal** : *can **to** go* est faux.
2. **Pas de double modal** : *will can* → *will be able to*.
3. **Pas de -s** à la 3e personne : *she can*, pas *she cans*.

<!-- extra -->
## Pièges des francophones

- **Pas de « to » après un modal** : *must **leave***, *can **attend*** (jamais *must to leave*). Exception : *have to, ought to, be able to*.
- **Pas de -s à la 3e personne** : *She **can** help* (pas *cans*).
- **Obligation** : *must* (forte), *have to* (externe), *should* (conseil). Interdiction : *must not* ≠ absence d'obligation : *don't have to*.
- **Probabilité** : *must* (quasi certain), *may/might* (possible), *can't* (impossible).
- **Passé** : *should have + p.p.* (reproche), *could have + p.p.* (possibilité manquée).

## Exemples en contexte

- *Visitors **must not** enter without a badge.*
- *You **don't have to** attend, but it is recommended.*

# Modal verbs

A modal is followed by the **bare infinitive** (no *to*) and never takes *-s* or *-ed*.

## Main meanings

| Modal | Meaning | Example |
| --- | --- | --- |
| **can / could** | ability, possibility, polite request | **Could** you send the file? |
| **may / might** | permission, possibility | The shipment **may** arrive late. |
| **must** | strong obligation, deduction | Employees **must** wear badges. |
| **have to** | external obligation | I **have to** renew my passport. |
| **should / ought to** | advice, weak obligation | You **should** back up your files. |
| **will / would** | future, offer, hypothesis | **Would** you like some tea? |
| **shall** | suggestion (I/we) | **Shall** we start? |

## Forms to know

- **Past / perfect**: modal + **have** + past participle: *The report **should have been** sent.*
- **Passive**: modal + **be** + past participle: *All forms **must be submitted**.*
- **Negation**: *must not* (forbidden) ≠ *do not have to* (not necessary).

## Traps

1. **No *to* after a modal**: *can **to** go* is wrong.
2. **No double modal**: *will can* → *will be able to*.
3. **No -s** in the third person: *she can*, not *she cans*.

## Traps for French speakers

- **No "to" after a modal**: *must **leave***, *can **attend*** (never "must to leave"). Exceptions: *have to, ought to, be able to*.
- **No -s in the third person**: *She **can** help* (not "cans").
- **Obligation**: *must* (strong), *have to* (external), *should* (advice). Prohibition: *must not* ≠ no obligation: *don't have to*.
- **Probability**: *must* (almost certain), *may/might* (possible), *can't* (impossible).
- **Past**: *should have + p.p.* (criticism), *could have + p.p.* (missed possibility).

## Examples in context

- *Visitors **must not** enter without a badge.*
- *You **don't have to** attend, but it is recommended.*
