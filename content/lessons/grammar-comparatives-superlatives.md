# Comparatifs et superlatifs

## Formation

| Adjectif | Comparatif | Superlatif |
| --- | --- | --- |
| court (1 syllabe) : fast | **fast**er **than** | **the** fast**est** |
| terminé en -y : busy | bus**ier** than | the bus**iest** |
| long (2+ syllabes) : efficient | **more** efficient **than** | **the most** efficient |
| irrégulier : good / bad / far | better / worse / farther | the best / the worst / the farthest |

## Égalité

*as + adjectif + as* : *The new model is **as fast as** the old one.* Négatif : *not as … as*.

## Règles importantes

1. **Comparatif + than** ; **superlatif + the** (et souvent *in/of* + groupe).
2. **Jamais de double comparatif** : *more faster* est faux.
3. **Renforcer un comparatif** : *much / far / even / significantly **more** efficient* (pas *very*).
4. **The + comparatif, the + comparatif** : *The sooner, the better.*
5. **Adverbes** : *more quickly*, *the most carefully*.

## Astuce

Dès que vous voyez **than**, éliminez la forme de base et le superlatif ; dès que vous voyez **the … of / in**, cherchez le superlatif.

<!-- extra -->
## Pièges des francophones

- **Mots courts : -er / -est ; mots longs : more / most.** *cheaper, the cheapest* / *more efficient, the most efficient*.
- **Pas de double comparatif** : *more cheaper* est faux. *cheaper*.
- **than, pas « that »** : *higher **than** expected*. En français on dit « que » : ne confondez pas.
- **Le superlatif prend « the »** et souvent *in/of* : *the largest company **in** the region.*
- **as… as** pour l'égalité : *as fast as*, *not as expensive as*.
- **The more… the more** : *The sooner you apply, the better your chances.*

## Exemples en contexte

- *Sales were **higher than** last year.*
- *This is **the most reliable** model we sell.*

# Comparatives and superlatives

## Formation

| Adjective | Comparative | Superlative |
| --- | --- | --- |
| short (1 syllable): fast | **fast**er **than** | **the** fast**est** |
| ending in -y: busy | bus**ier** than | the bus**iest** |
| long (2+ syllables): efficient | **more** efficient **than** | **the most** efficient |
| irregular: good / bad / far | better / worse / farther | the best / the worst / the farthest |

## Equality

*as + adjective + as*: *The new model is **as fast as** the old one.* Negative: *not as … as*.

## Important rules

1. **Comparative + than**; **superlative + the** (often *in/of* + group).
2. **Never a double comparative**: *more faster* is wrong.
3. **Strengthening a comparative**: *much / far / even / significantly **more** efficient* (not *very*).
4. **The + comparative, the + comparative**: *The sooner, the better.*
5. **Adverbs**: *more quickly*, *the most carefully*.

## Tip

As soon as you see **than**, eliminate the base form and the superlative; when you see **the … of / in**, look for the superlative.

## Traps for French speakers

- **Short words: -er / -est; long words: more / most.** *cheaper, the cheapest* / *more efficient, the most efficient*.
- **No double comparative**: "more cheaper" is wrong. *cheaper*.
- **than, not "that"**: *higher **than** expected*.
- **The superlative takes "the"** and often *in/of*: *the largest company **in** the region.*
- **as… as** for equality: *as fast as*, *not as expensive as*.
- **The more… the more**: *The sooner you apply, the better your chances.*

## Examples in context

- *Sales were **higher than** last year.*
- *This is **the most reliable** model we sell.*
