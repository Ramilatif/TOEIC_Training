# Articles et déterminants

## A / an / the / rien

| Situation | Article | Exemple |
| --- | --- | --- |
| Nom comptable singulier, **première mention** | **a / an** | We hired **an** assistant. |
| Chose déjà mentionnée ou unique | **the** | **The** assistant starts Monday. |
| Nom comptable **pluriel**, sens général | rien | **Managers** attend the meeting. |
| Nom **indénombrable**, sens général | rien | **Information** is power. |

*an* devant un **son** voyelle (*an hour*, *an MBA*), *a* devant un son consonne (*a university*).

## Déterminants à bien distinguer

- **each / every** + nom **singulier** (+ verbe singulier)
- **another** = un autre (singulier) ; **other** + pluriel ; **the other** = le/les autre(s) déterminé(s)
- **this/that** (singulier), **these/those** (pluriel)
- **either / neither** + singulier
- **all / most / some** + pluriel ou indénombrable

## Pièges TOEIC

1. **another + nom pluriel** est faux (sauf *another two days*).
2. **Pas d'article** devant un possessif : *the my report* est faux.
3. **Nom indénombrable** (advice, equipment, furniture, information) : jamais *a* ni de pluriel.

<!-- extra -->
## Pièges des francophones

- **Pas d'article devant un nom non dénombrable général** : *Information is power.* (en français : « l'information »).
- **a / an selon le son** : *an hour, an MBA* (son voyelle), *a university, a European firm* (son consonne).
- **the** pour ce qui est déjà identifié ou unique : *the CEO, the report we discussed*.
- **Pas de « the » avec les noms de villes, de personnes, de jours seuls** : *in Paris, on Monday*.
- **Déterminants distincts** : *this/these* (proche), *that/those* (éloigné) ; *another* + singulier, *other* + pluriel.

## Exemples en contexte

- *She is **an** honest manager.*
- *We need **another** copy of **the** contract.*

# Articles and determiners

## A / an / the / nothing

| Situation | Article | Example |
| --- | --- | --- |
| Singular countable noun, **first mention** | **a / an** | We hired **an** assistant. |
| Already mentioned or unique | **the** | **The** assistant starts Monday. |
| **Plural** countable noun, general sense | none | **Managers** attend the meeting. |
| **Uncountable** noun, general sense | none | **Information** is power. |

*an* before a vowel **sound** (*an hour*, *an MBA*), *a* before a consonant sound (*a university*).

## Determiners to tell apart

- **each / every** + **singular** noun (+ singular verb)
- **another** = one more (singular); **other** + plural; **the other** = the remaining one(s)
- **this/that** (singular), **these/those** (plural)
- **either / neither** + singular
- **all / most / some** + plural or uncountable

## TOEIC traps

1. **another + plural noun** is wrong (except *another two days*).
2. **No article** before a possessive: *the my report* is wrong.
3. **Uncountable nouns** (advice, equipment, furniture, information): never *a* or a plural.

## Traps for French speakers

- **No article before a general uncountable noun**: *Information is power.* (French says "l'information").
- **a / an depends on the sound**: *an hour, an MBA* (vowel sound), *a university, a European firm* (consonant sound).
- **the** for something already identified or unique: *the CEO, the report we discussed*.
- **No "the" with cities, people, or days alone**: *in Paris, on Monday*.
- **Distinct determiners**: *this/these* (near), *that/those* (far); *another* + singular, *other* + plural.

## Examples in context

- *She is **an** honest manager.*
- *We need **another** copy of **the** contract.*
