# Vocabulaire : restauration et événements

Réservations, traiteur, banquets : thème fréquent en Parts 1, 2, 3 et 7.

## Mots essentiels

| Mot | Traduction | Exemple |
| --- | --- | --- |
| **catering** | service traiteur | Catering is included. |
| **reservation** | réservation | A table reservation for six. |
| **menu** | menu / carte | The menu changes weekly. |
| **banquet** | banquet | The banquet is on Friday. |
| **beverage** | boisson | Beverages are free. |
| **appetizer** | entrée | Try the appetizer. |
| **server** | serveur | The server took our order. |
| **venue** | lieu (événement) | The venue holds 200 guests. |
| **RSVP** | répondre à une invitation | Please RSVP by Friday. |
| **seating** | placement | Seating is limited. |
| **tip** | pourboire | A tip is included. |
| **dietary restrictions** | restrictions alimentaires | Please list dietary restrictions. |

## Collocations et expressions utiles

- **book a table** : réserver une table
- **fully booked** : complet
- **on the house** : offert par la maison
- **take an order** : prendre une commande
- **reception** : réception

## Astuce TOEIC

Aux questions de Part 2 sur une réservation, une réponse sur l'heure ou le nombre de personnes est souvent correcte.

Ajoutez ces mots à vos flashcards pour les réviser avec la répétition espacée.

# Vocabulary: dining and events

Reservations, catering, banquets: a frequent theme in Parts 1, 2, 3 and 7.

## Key words

| Word | Meaning | Example |
| --- | --- | --- |
| **catering** | providing food for an event | Catering is included. |
| **reservation** | a table or room booked in advance | A table reservation for six. |
| **menu** | a list of dishes | The menu changes weekly. |
| **banquet** | a large formal meal | The banquet is on Friday. |
| **beverage** | a drink | Beverages are free. |
| **appetizer** | a small dish before the main course | Try the appetizer. |
| **server** | a person who serves food | The server took our order. |
| **venue** | the place where an event happens | The venue holds 200 guests. |
| **RSVP** | a request to reply to an invitation | Please RSVP by Friday. |
| **seating** | arrangement of seats | Seating is limited. |
| **tip** | extra money for good service | A tip is included. |
| **dietary restrictions** | foods a person cannot eat | Please list dietary restrictions. |

## Useful collocations and expressions

- **book a table**
- **fully booked**
- **on the house**
- **take an order**
- **reception**

## TOEIC tip

For Part 2 questions about a reservation, an answer about the time or number of guests is often correct.
