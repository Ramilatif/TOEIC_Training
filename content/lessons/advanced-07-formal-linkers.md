# Connecteurs et organisation du discours (niveau soutenu)

Au C1, on attend de vous une **cohésion fine** : choisir le bon connecteur selon le registre et la structure de la phrase.

## 1. Opposition et concession

| Connecteur | Suivi de | Exemple |
| --- | --- | --- |
| **Although / Even though / Though** | proposition | *Although it was costly, we proceeded.* |
| **Whereas / While** | proposition (contraste) | *Sales rose, **whereas** costs fell.* |
| **Despite / In spite of / Notwithstanding** | nom, -ing | ***Notwithstanding** the delay, we finished on time.* |
| **However / Nevertheless / Nonetheless / Even so** | phrase suivante, virgule | *It was costly. **Nevertheless**, we proceeded.* |
| **albeit** | adjectif ou groupe court | *A useful, **albeit** limited, tool.* |
| **Be that as it may** | phrase suivante | ***Be that as it may**, we must decide.* |

## 2. Cause et conséquence

| Connecteur | Suivi de | Exemple |
| --- | --- | --- |
| **Owing to / Due to / Because of** | nom | ***Owing to** heavy rain, the event was cancelled.* |
| **Since / As / Given that** | proposition | ***Given that** funds are limited, we must prioritize.* |
| **Therefore / Consequently / Hence / Thus** | phrase suivante | *Demand is high; **hence** the price increase.* |
| **thereby / whereby** | participe / proposition | *We cut costs, **thereby** raising profit.* |
| **so … that / such … that** | proposition | *It was **so** urgent **that** we replied at once.* |

## 3. Condition et limite

| Connecteur | Sens | Exemple |
| --- | --- | --- |
| **provided (that) / providing / on condition that** | à condition que | *We will sign **provided that** the terms are met.* |
| **as long as** | tant que | *You may stay **as long as** you wish.* |
| **unless** | à moins que | ***Unless** we act, the market will collapse.* |
| **insofar as / in so far as** | dans la mesure où | *The plan is sound **insofar as** it is realistic.* |
| **otherwise** | sinon | *Sign today; **otherwise** the offer lapses.* |

## 4. Addition, exemple, reformulation, conclusion

| Fonction | Connecteurs |
| --- | --- |
| **Addition** | moreover, furthermore, in addition, besides, what is more |
| **Exemple** | for instance, for example, namely, in particular |
| **Reformulation** | in other words, that is to say, i.e. |
| **Ordre** | firstly… secondly… finally ; to begin with ; subsequently |
| **Conclusion** | in conclusion, to sum up, all things considered |

## Pièges

- **Despite + proposition est faux** : *Despite **it was** late* ✘ → *Despite **being** late* / *Despite **the fact that** it was late* ✔.
- **However** n'est jamais une conjonction : un point ou un point-virgule le précède.
- **Whereas** insiste sur le contraste ; **while** peut aussi signifier « pendant que ».
- **Hence** et **thus** sont suivis d'un nom ou d'une proposition, jamais de *that*.

# Formal linkers and discourse organization

At C1 you are expected to show **fine cohesion**: choosing the right linker for the register and sentence structure.

## 1. Contrast and concession

| Linker | Followed by | Example |
| --- | --- | --- |
| **Although / Even though / Though** | clause | *Although it was costly, we proceeded.* |
| **Whereas / While** | clause (contrast) | *Sales rose, **whereas** costs fell.* |
| **Despite / In spite of / Notwithstanding** | noun, -ing | ***Notwithstanding** the delay, we finished on time.* |
| **However / Nevertheless / Nonetheless / Even so** | next sentence, comma | *It was costly. **Nevertheless**, we proceeded.* |
| **albeit** | adjective or short phrase | *A useful, **albeit** limited, tool.* |
| **Be that as it may** | next sentence | ***Be that as it may**, we must decide.* |

## 2. Cause and result

| Linker | Followed by | Example |
| --- | --- | --- |
| **Owing to / Due to / Because of** | noun | ***Owing to** heavy rain, the event was cancelled.* |
| **Since / As / Given that** | clause | ***Given that** funds are limited, we must prioritize.* |
| **Therefore / Consequently / Hence / Thus** | next sentence | *Demand is high; **hence** the price increase.* |
| **thereby / whereby** | participle / clause | *We cut costs, **thereby** raising profit.* |
| **so … that / such … that** | clause | *It was **so** urgent **that** we replied at once.* |

## 3. Condition and limit

| Linker | Meaning | Example |
| --- | --- | --- |
| **provided (that) / providing / on condition that** | on condition that | *We will sign **provided that** the terms are met.* |
| **as long as** | as long as | *You may stay **as long as** you wish.* |
| **unless** | if not | ***Unless** we act, the market will collapse.* |
| **insofar as / in so far as** | to the extent that | *The plan is sound **insofar as** it is realistic.* |
| **otherwise** | or else | *Sign today; **otherwise** the offer lapses.* |

## 4. Addition, example, rephrasing, conclusion

| Function | Linkers |
| --- | --- |
| **Addition** | moreover, furthermore, in addition, besides, what is more |
| **Example** | for instance, for example, namely, in particular |
| **Rephrasing** | in other words, that is to say, i.e. |
| **Order** | firstly… secondly… finally; to begin with; subsequently |
| **Conclusion** | in conclusion, to sum up, all things considered |

## Traps

- **Despite + clause is wrong**: *Despite **it was** late* ✘ → *Despite **being** late* / *Despite **the fact that** it was late* ✔.
- **However** is never a conjunction: a period or semicolon precedes it.
- **Whereas** stresses contrast; **while** can also mean "at the same time as".
- **Hence** and **thus** are followed by a noun or a clause, never by *that*.
