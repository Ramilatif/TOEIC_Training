# Expressions idiomatiques du monde professionnel

Les **idiomes** sont omniprésents dans les dialogues Part 3 et 4 : un locuteur dit *We're back to square one* et la question demande ce qu'il veut dire. Vous devez comprendre le sens, pas la lettre.

## Les mots et expressions

| Terme | Traduction | Exemple |
| --- | --- | --- |
| **back to square one** | retour à la case départ | The test failed, so we're back to square one. |
| **a ballpark figure** | un chiffre approximatif | Can you give me a ballpark figure for the cost? |
| **touch base** | prendre contact, faire le point | Let's touch base on Monday. |
| **get the ball rolling** | lancer les choses | Let's get the ball rolling with a kickoff meeting. |
| **on the same page** | sur la même longueur d'onde | Before we go on, let's make sure we're on the same page. |
| **in the pipeline** | en préparation | Several new products are in the pipeline. |
| **cut corners** | faire des économies au détriment de la qualité | We refuse to cut corners on safety. |
| **keep someone in the loop** | tenir quelqu'un informé | Please keep me in the loop about the schedule. |
| **down to the wire** | jusqu'à la dernière minute | The negotiation went down to the wire. |
| **hit the ground running** | démarrer sur les chapeaux de roues | She hit the ground running in her new role. |
| **think outside the box** | sortir des sentiers battus | We need to think outside the box. |
| **bite the bullet** | se résoudre à faire quelque chose de pénible | We had to bite the bullet and cut jobs. |
| **call it a day** | arrêter pour aujourd'hui | It's late; let's call it a day. |
| **raise the bar** | relever le niveau | The new model raises the bar for the industry. |
| **a win-win situation** | une situation gagnant-gagnant | This deal is a win-win situation. |
| **in the red / in the black** | dans le rouge / bénéficiaire | The firm is finally in the black. |
| **take on board** | prendre en compte | We will take your suggestions on board. |
| **the bottom line** | l'essentiel, le résultat net | The bottom line is that we need more staff. |

## Comment les apprendre

Apprenez chaque idiome **dans une phrase complète**. Au TOEIC, la bonne réponse reformule l'idiome : *touch base* = *contact* ; *get the ball rolling* = *begin*. Évitez de les employer à l'écrit très formel.

Ajoutez ces termes à vos flashcards pour les réviser avec la répétition espacée.

# Business idioms

**Idioms** are everywhere in Part 3 and 4 dialogues: a speaker says *We're back to square one* and the question asks what they mean. You must understand the meaning, not the words.

## Words and expressions

| Term | Meaning | Example |
| --- | --- | --- |
| **back to square one** | start again from the beginning | The test failed, so we're back to square one. |
| **a ballpark figure** | a rough estimate | Can you give me a ballpark figure for the cost? |
| **touch base** | contact briefly | Let's touch base on Monday. |
| **get the ball rolling** | start a process | Let's get the ball rolling with a kickoff meeting. |
| **on the same page** | in agreement | Before we go on, let's make sure we're on the same page. |
| **in the pipeline** | being planned or developed | Several new products are in the pipeline. |
| **cut corners** | do something cheaply and badly | We refuse to cut corners on safety. |
| **keep someone in the loop** | keep informed | Please keep me in the loop about the schedule. |
| **down to the wire** | until the last moment | The negotiation went down to the wire. |
| **hit the ground running** | start working effectively at once | She hit the ground running in her new role. |
| **think outside the box** | think creatively | We need to think outside the box. |
| **bite the bullet** | accept something unpleasant | We had to bite the bullet and cut jobs. |
| **call it a day** | stop working | It's late; let's call it a day. |
| **raise the bar** | set a higher standard | The new model raises the bar for the industry. |
| **a win-win situation** | good for both sides | This deal is a win-win situation. |
| **in the red / in the black** | losing money / making profit | The firm is finally in the black. |
| **take on board** | accept and consider | We will take your suggestions on board. |
| **the bottom line** | the key point or net result | The bottom line is that we need more staff. |

## How to learn them

Learn each idiom **in a full sentence**. On the TOEIC the right answer paraphrases the idiom: *touch base* = *contact*; *get the ball rolling* = *begin*. Avoid them in very formal writing.

Add these terms to your flashcards to review them with spaced repetition.
