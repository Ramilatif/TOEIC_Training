# Nominalisation et style formel

La **nominalisation** transforme un verbe ou un adjectif en **nom**. C'est la marque du style écrit formel (rapports, contrats, articles) et un piège classique en Part 5.

## 1. Du verbe au nom

| Verbe | Nom | Suffixe |
| --- | --- | --- |
| implement | implementation | -ation |
| assess | assessment | -ment |
| consider | consideration | -ation |
| comply | compliance | -ance |
| reduce | reduction | -tion |
| adjust | adjustment | -ment |
| fail | failure | -ure |
| decide | decision | -ion |
| prefer | preference | -ence |
| grow | growth | irrégulier |
| deliver | delivery | -y |

## 2. De l'adjectif au nom

| Adjectif | Nom |
| --- | --- |
| able | ability |
| available | availability |
| efficient | efficiency |
| safe | safety |
| long | length |
| important | importance |
| flexible | flexibility |
| responsible | responsibility |

## 3. Style verbal → style nominal

| Style verbal (plus oral) | Style nominal (plus formel) |
| --- | --- |
| *We **decided** to close the branch because sales **fell**.* | *The **decision** to close the branch followed a **fall** in sales.* |
| *They **implemented** the plan quickly.* | *The **implementation** of the plan was swift.* |
| *The firm **grew** fast.* | *The firm experienced rapid **growth**.* |
| *If we **comply** with the rules, we avoid fines.* | ***Compliance** with the rules avoids fines.* |

## 4. Collocations avec les noms abstraits

- **conduct** an assessment · **carry out** an investigation · **reach** a decision
- **raise** a concern · **meet** a requirement · **place** emphasis on
- **a sharp / steady / sudden** increase · **a marked** improvement

## 5. Repérer la bonne forme en Part 5

1. Regardez **ce qui précède** : un article, un adjectif ou un possessif → **nom** (*the implementation*).
2. Regardez **ce qui suit** : *of* ou une préposition → souvent un **nom** (*the assessment of the risks*).
3. Après un **verbe** : adverbe ou complément ; après *be* : adjectif ou participe.

## Pièges

- **Suffixes trompeurs** : *economic* (adjectif) ≠ *economy* (nom) ≠ *economics* (matière).
- **Singulier / pluriel / non dénombrable** : *progress*, *advice*, *information*, *research* sont non dénombrables.
- **Deux noms proches** : *departure* (action de partir) ≠ *department* ; *proposal* (offre) ≠ *proposition* (énoncé).

# Nominalization and formal style

**Nominalization** turns a verb or adjective into a **noun**. It is the mark of formal written style (reports, contracts, articles) and a classic Part 5 trap.

## 1. From verb to noun

| Verb | Noun | Suffix |
| --- | --- | --- |
| implement | implementation | -ation |
| assess | assessment | -ment |
| consider | consideration | -ation |
| comply | compliance | -ance |
| reduce | reduction | -tion |
| adjust | adjustment | -ment |
| fail | failure | -ure |
| decide | decision | -ion |
| prefer | preference | -ence |
| grow | growth | irregular |
| deliver | delivery | -y |

## 2. From adjective to noun

| Adjective | Noun |
| --- | --- |
| able | ability |
| available | availability |
| efficient | efficiency |
| safe | safety |
| long | length |
| important | importance |
| flexible | flexibility |
| responsible | responsibility |

## 3. Verbal style → nominal style

| Verbal style (more spoken) | Nominal style (more formal) |
| --- | --- |
| *We **decided** to close the branch because sales **fell**.* | *The **decision** to close the branch followed a **fall** in sales.* |
| *They **implemented** the plan quickly.* | *The **implementation** of the plan was swift.* |
| *The firm **grew** fast.* | *The firm experienced rapid **growth**.* |
| *If we **comply** with the rules, we avoid fines.* | ***Compliance** with the rules avoids fines.* |

## 4. Collocations with abstract nouns

- **conduct** an assessment · **carry out** an investigation · **reach** a decision
- **raise** a concern · **meet** a requirement · **place** emphasis on
- **a sharp / steady / sudden** increase · **a marked** improvement

## 5. Spotting the right form in Part 5

1. Look at **what comes before**: an article, adjective or possessive → **noun** (*the implementation*).
2. Look at **what comes after**: *of* or a preposition → often a **noun** (*the assessment of the risks*).
3. After a **verb**: adverb or object; after *be*: adjective or participle.

## Traps

- **Misleading suffixes**: *economic* (adjective) ≠ *economy* (noun) ≠ *economics* (subject).
- **Singular / plural / uncountable**: *progress*, *advice*, *information*, *research* are uncountable.
- **Close nouns**: *departure* (leaving) ≠ *department*; *proposal* (offer) ≠ *proposition* (statement).
