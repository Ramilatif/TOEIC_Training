# Mots qui se ressemblent (confusables)

Le TOEIC (Part 5) adore opposer des mots **qui se ressemblent** par la forme ou le son mais dont le sens diffère. Une seule lettre change tout.

## Les mots et expressions

| Terme | Traduction | Exemple |
| --- | --- | --- |
| **affect / effect** | affecter (verbe) / effet (nom) | The delay affected sales; its effect was serious. |
| **principal / principle** | principal (adj.) / principe (nom) | The principal reason is cost; it is a matter of principle. |
| **stationary / stationery** | immobile / papeterie | Order stationery for the office. |
| **complement / compliment** | compléter / compliment | The wine complements the meal. |
| **economic / economical** | économique (de l'économie) / économique (bon marché) | An economical car in an economic crisis. |
| **council / counsel** | conseil (assemblée) / conseil (avis) | The council sought legal counsel. |
| **proceed / precede** | continuer / précéder | Please proceed to Gate 4. |
| **accept / except** | accepter / sauf | All staff except managers attend. |
| **formerly / formally** | autrefois / officiellement | He was formerly a director; he formally resigned. |
| **later / latter** | plus tard / ce dernier | Of the two options, the latter is cheaper. |
| **loose / lose** | lâche / perdre | Don't lose the loose papers. |
| **sight / site / cite** | vue / site / citer | Cite the site you used. |
| **emigrate / immigrate** | émigrer / immigrer | She emigrated from Peru and immigrated to Spain. |
| **alternate / alternative** | alterner / alternative | We need an alternative plan. |
| **lay / lie** | poser / être allongé | Lay the files on the desk. |
| **raise / rise** | lever / s'élever | Prices rise; the firm raises them. |
| **beside / besides** | à côté de / de plus | Besides, it sits beside the entrance. |
| **ensure / insure / assure** | garantir / assurer (assurance) / assurer (rassurer) | Ensure that the goods are insured. |

## Comment les apprendre

Apprenez les paires **en contexte** et notez la nature de chaque mot : *affect* est un **verbe**, *effect* un **nom**. En Part 5, regardez d'abord la nature grammaticale attendue.

Ajoutez ces termes à vos flashcards pour les réviser avec la répétition espacée.

# Confusable words

The TOEIC (Part 5) loves to pit words that **look or sound alike** but differ in meaning. A single letter changes everything.

## Words and expressions

| Term | Meaning | Example |
| --- | --- | --- |
| **affect / effect** | to influence / a result | The delay affected sales; its effect was serious. |
| **principal / principle** | main / rule | The principal reason is cost; it is a matter of principle. |
| **stationary / stationery** | not moving / paper goods | Order stationery for the office. |
| **complement / compliment** | add to / praise | The wine complements the meal. |
| **economic / economical** | of the economy / cheap to use | An economical car in an economic crisis. |
| **council / counsel** | committee / advice | The council sought legal counsel. |
| **proceed / precede** | go on / come before | Please proceed to Gate 4. |
| **accept / except** | receive / apart from | All staff except managers attend. |
| **formerly / formally** | in the past / officially | He was formerly a director; he formally resigned. |
| **later / latter** | after / the second of two | Of the two options, the latter is cheaper. |
| **loose / lose** | not tight / fail to keep | Don't lose the loose papers. |
| **sight / site / cite** | vision / place / quote | Cite the site you used. |
| **emigrate / immigrate** | leave a country / enter a country | She emigrated from Peru and immigrated to Spain. |
| **alternate / alternative** | take turns / other option | We need an alternative plan. |
| **lay / lie** | put down / recline | Lay the files on the desk. |
| **raise / rise** | lift something / go up | Prices rise; the firm raises them. |
| **beside / besides** | next to / in addition | Besides, it sits beside the entrance. |
| **ensure / insure / assure** | make certain / cover by insurance / reassure | Ensure that the goods are insured. |

## How to learn them

Learn the pairs **in context** and note the word class of each: *affect* is a **verb**, *effect* a **noun**. In Part 5, first look at the grammatical class expected.

Add these terms to your flashcards to review them with spaced repetition.
