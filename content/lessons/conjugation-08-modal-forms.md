# Les formes des modaux

Les modaux : **can, could, may, might, must, shall, should, will, would**.

## Règles de forme

| Règle | Exemple |
| --- | --- |
| Pas de **-s** à la 3e personne | *She **can** help.* (pas *cans*) |
| **Base verbale** derrière, sans *to* | *You **must leave**.* (pas *must to leave*) |
| Négation : **not** après le modal | *He **cannot** / **may not** / **must not** attend.* |
| Question : le modal passe devant le sujet | ***Can** you help me?* |
| Pas de **do** pour la question ou la négation | *Should we go?* (pas *Do we should go?*) |

## Les modaux au passé : modal + have + participe passé

| Forme | Sens | Exemple |
| --- | --- | --- |
| **should have** + p.p. | reproche, regret | *You **should have called**.* |
| **could have** + p.p. | possibilité manquée | *We **could have won**.* |
| **must have** + p.p. | déduction (quasi certain) | *He **must have left**.* |
| **might / may have** + p.p. | possibilité (peut-être) | *She **might have forgotten**.* |
| **would have** + p.p. | irréel du passé | *I **would have helped**.* |

## Équivalents (pour les temps manquants)

| Modal | Équivalent | Exemple |
| --- | --- | --- |
| can | **be able to** | *We **will be able to** deliver on Monday.* |
| must | **have to** | *We **had to** cancel.* |
| may (permission) | **be allowed to** | *Employees **are allowed to** work remotely.* |

## Pièges des francophones

- **Pas de *to* après un modal** : *can **to** go* est faux.
- **must not ≠ don't have to** : *must not* = interdit, *don't have to* = pas obligé.
- **Un seul modal** : *will can* est faux → *will be able to*.
- **should have** + participe passé (pas *should had*).

# Modal verb forms

Modals: **can, could, may, might, must, shall, should, will, would**.

## Form rules

| Rule | Example |
| --- | --- |
| No **-s** in the third person | *She **can** help.* (not *cans*) |
| **Base form** after it, without *to* | *You **must leave**.* (not *must to leave*) |
| Negative: **not** after the modal | *He **cannot** / **may not** / **must not** attend.* |
| Question: the modal goes before the subject | ***Can** you help me?* |
| No **do** for questions or negatives | *Should we go?* (not *Do we should go?*) |

## Modals in the past: modal + have + past participle

| Form | Meaning | Example |
| --- | --- | --- |
| **should have** + p.p. | criticism, regret | *You **should have called**.* |
| **could have** + p.p. | missed possibility | *We **could have won**.* |
| **must have** + p.p. | deduction (almost certain) | *He **must have left**.* |
| **might / may have** + p.p. | possibility (maybe) | *She **might have forgotten**.* |
| **would have** + p.p. | unreal past | *I **would have helped**.* |

## Equivalents (for missing tenses)

| Modal | Equivalent | Example |
| --- | --- | --- |
| can | **be able to** | *We **will be able to** deliver on Monday.* |
| must | **have to** | *We **had to** cancel.* |
| may (permission) | **be allowed to** | *Employees **are allowed to** work remotely.* |

## Traps for French speakers

- **No *to* after a modal**: *can **to** go* is wrong.
- **must not ≠ don't have to**: *must not* = forbidden, *don't have to* = not required.
- **Only one modal**: *will can* is wrong → *will be able to*.
- **should have** + past participle (not *should had*).
