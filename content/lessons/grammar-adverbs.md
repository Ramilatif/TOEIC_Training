# Adverbes : formes et place

Un adverbe modifie un verbe, un adjectif, un autre adverbe ou toute une phrase. Au TOEIC, il est souvent le « mot manquant » de la Part 5.

## Formation

- Adjectif + **-ly** : *quick → quickly*, *careful → carefully*.
- **-y → -ily** : *easy → easily*.
- Adjectifs en **-ic** → **-ically** : *economic → economically*.
- Irréguliers : *good → well*, *fast → fast*, *hard → hard*, *late → late*.

## Place de l'adverbe

| Place | Exemple |
| --- | --- |
| Entre l'auxiliaire et le participe | *We have **already** sent it.* |
| Avant le verbe principal (fréquence) | *She **always** arrives early.* |
| Après le verbe ou le complément (manière) | *He speaks **clearly**.* |
| Devant un adjectif | *a **highly** qualified candidate* |
| En début de phrase (+ virgule) | ***Unfortunately**, the flight was cancelled.* |

## Adverbes de degré à connaître

*very, quite, rather, extremely, highly, fairly, slightly, nearly, almost*.

## Pièges des francophones

- Ne placez jamais l'adverbe entre le verbe et son complément : *She speaks **well** English* est faux → *She speaks English **well**.*
- *Hard* ≠ *hardly* (à peine). *Late* ≠ *lately* (récemment).
- *Already* = affirmation, *yet* = négation/question, *still* = toujours.

# Adverbs: form and position

An adverb modifies a verb, an adjective, another adverb or a whole sentence. On the TOEIC it is often the "missing word" in Part 5.

## Formation

- Adjective + **-ly**: *quick → quickly*, *careful → carefully*.
- **-y → -ily**: *easy → easily*.
- Adjectives in **-ic** → **-ically**: *economic → economically*.
- Irregular: *good → well*, *fast → fast*, *hard → hard*, *late → late*.

## Position

| Position | Example |
| --- | --- |
| Between auxiliary and participle | *We have **already** sent it.* |
| Before the main verb (frequency) | *She **always** arrives early.* |
| After the verb or object (manner) | *He speaks **clearly**.* |
| Before an adjective | *a **highly** qualified candidate* |
| Sentence start (+ comma) | ***Unfortunately**, the flight was cancelled.* |

## Degree adverbs to know

*very, quite, rather, extremely, highly, fairly, slightly, nearly, almost*.

## Traps for French speakers

- Never put the adverb between the verb and its object: "She speaks well English" is wrong → *She speaks English **well**.*
- *Hard* ≠ *hardly* (barely). *Late* ≠ *lately* (recently).
- *Already* = affirmative, *yet* = negative/question, *still* = continuing.
