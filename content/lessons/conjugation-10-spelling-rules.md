# Orthographe des terminaisons -s, -ed et -ing

Les erreurs d'orthographe de conjugaison sont fréquentes dans les réponses TOEIC. Voici les règles qui couvrent presque tous les cas.

## Terminaison -s (3e personne du présent, pluriel)

| Fin du mot | Règle | Exemple |
| --- | --- | --- |
| consonne + **y** | y → **ies** | study → studies, carry → carries |
| voyelle + **y** | + **s** | play → plays, buy → buys |
| **s, sh, ch, x, z** | + **es** | pass → passes, watch → watches |
| **o** (quelques verbes) | + **es** | go → goes, do → does |
| le reste | + **s** | work → works |

## Terminaison -ed (prétérit, participe passé réguliers)

| Fin du verbe | Règle | Exemple |
| --- | --- | --- |
| **e** | + **d** | arrive → arrived, hope → hoped |
| consonne + **y** | y → **ied** | study → studied, carry → carried |
| voyelle + **y** | + **ed** | play → played |
| **1 voyelle + 1 consonne**, mot court accentué | consonne **doublée** | stop → stopped, plan → planned |
| autre | + **ed** | work → worked |

## Terminaison -ing (forme progressive, gérondif)

| Fin du verbe | Règle | Exemple |
| --- | --- | --- |
| **e** muet | e **supprimé** | make → making, arrive → arriving |
| **ie** | ie → **y** + ing | lie → lying, die → dying |
| **1 voyelle + 1 consonne**, mot court accentué | consonne **doublée** | stop → stopping, begin → beginning |
| **y** | y conservé | study → studying, play → playing |
| autre | + **ing** | work → working |

## Cas particuliers

- *Travel* : **travelled** (britannique) / **traveled** (américain). Les deux sont acceptés.
- Verbes en **-c** : *panic → panicked, panicking*.
- Verbes de deux syllabes accentués sur la 1re : pas de doublement (*open → opened, opening* ; *visit → visited*), mais accentués sur la 2e : doublement (*begin → beginning*, *prefer → preferred*).

## Pièges des francophones

- **Pas de doublement au pluriel** : *a plan, plans* (pas *planns*).
- **Ne pas écrire** : *studing, makeing, stoped, carryed*.
- **Verbe + y** : *buys, plays* (pas *buies*).

# Spelling rules for -s, -ed and -ing

Conjugation spelling mistakes are common in TOEIC answer choices. These rules cover almost every case.

## -s ending (third person present, plurals)

| Word ending | Rule | Example |
| --- | --- | --- |
| consonant + **y** | y → **ies** | study → studies, carry → carries |
| vowel + **y** | + **s** | play → plays, buy → buys |
| **s, sh, ch, x, z** | + **es** | pass → passes, watch → watches |
| **o** (a few verbs) | + **es** | go → goes, do → does |
| the rest | + **s** | work → works |

## -ed ending (regular past and past participle)

| Verb ending | Rule | Example |
| --- | --- | --- |
| **e** | + **d** | arrive → arrived, hope → hoped |
| consonant + **y** | y → **ied** | study → studied, carry → carried |
| vowel + **y** | + **ed** | play → played |
| **1 vowel + 1 consonant**, short stressed word | consonant **doubled** | stop → stopped, plan → planned |
| other | + **ed** | work → worked |

## -ing ending (progressive, gerund)

| Verb ending | Rule | Example |
| --- | --- | --- |
| silent **e** | e **dropped** | make → making, arrive → arriving |
| **ie** | ie → **y** + ing | lie → lying, die → dying |
| **1 vowel + 1 consonant**, short stressed word | consonant **doubled** | stop → stopping, begin → beginning |
| **y** | y kept | study → studying, play → playing |
| other | + **ing** | work → working |

## Special cases

- *Travel*: **travelled** (British) / **traveled** (American). Both are accepted.
- Verbs ending in **-c**: *panic → panicked, panicking*.
- Two-syllable verbs stressed on the first syllable: no doubling (*open → opened, opening*; *visit → visited*); stressed on the second: doubling (*begin → beginning*, *prefer → preferred*).

## Traps for French speakers

- **No doubling in plurals**: *a plan, plans* (not *planns*).
- **Do not write**: *studing, makeing, stoped, carryed*.
- **Verb + y**: *buys, plays* (not *buies*).
