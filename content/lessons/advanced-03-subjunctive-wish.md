# Subjonctif, wish et structures hypothétiques

Le C1 attend que vous reconnaissiez des **structures hypothétiques** qui n'utilisent pas le conditionnel classique.

## 1. Le subjonctif « mandatif » (formel)

Après des verbes ou adjectifs qui expriment **ordre, exigence, recommandation**, on emploie la **base verbale** (sans -s, sans *to*) :

***insist, demand, require, recommend, suggest, propose, request, ask*** + *that* + sujet + **base**
***it is essential / vital / important / necessary / advisable that*** + sujet + **base**

- *We recommend that she **apply** before Friday.* (pas *applies*)
- *It is essential that the report **be** submitted today.* (pas *is*)
- *The board insisted that he **not** attend.* (négation = *not* + base)

En anglais britannique, on trouve aussi *should* : *We recommend that she **should apply**.*

## 2. Wish et if only

| Situation | Forme | Exemple |
| --- | --- | --- |
| **Regret présent** (irréel) | wish + **prétérit** | *I wish I **had** more time.* · *I wish I **were** taller.* |
| **Regret passé** | wish + **had + participe** | *I wish I **had accepted** the offer.* |
| **Plainte / souhait de changement** | wish + **would** | *I wish he **would** answer emails.* |
| **if only** (plus fort) | même construction | *If only we **had known**.* |

## 3. would rather, it is (high) time, as if / as though

| Structure | Forme | Exemple |
| --- | --- | --- |
| **would rather** + sujet différent | + **prétérit** | *I would rather you **sent** it today.* |
| **would rather** + même sujet | + **base** | *I would rather **wait**.* |
| **It is (high) time** | + **prétérit** | *It is time we **reviewed** the budget.* |
| **as if / as though** (irréel) | + **prétérit** (were) | *He acts as if he **were** the director.* |
| **suppose / supposing** | + prétérit / present | *Suppose we **lost** the contract?* |

## 4. Formes hypothétiques de style soutenu

- ***were to*** : *If the market **were to** collapse, we would adapt.* (hypothèse peu probable)
- ***should*** : *If you **should** need…* (hypothèse peu probable)
- ***but for*** : ***But for** your help, we would have failed.* (= sans)
- ***otherwise*** : *Sign now; **otherwise** the offer expires.*

## Pièges des francophones

- **Pas de -s au subjonctif** : *He insists that she **go*** (pas *goes*).
- **Pas de futur ni de conditionnel après wish** : *I wish it **were** easier* (pas *would be* pour un état).
- **were pour tous les sujets** en style soigné : *If I **were** you*, *as if he **were***.
- **Ne pas confondre** : *I wish you **would** help* (plainte) ≠ *I hope you **will** help* (espoir réel).

# Subjunctive, wish and hypothetical structures

C1 expects you to recognize **hypothetical structures** that do not use the classic conditional.

## 1. The mandative subjunctive (formal)

After verbs or adjectives expressing **order, demand, recommendation**, use the **base form** (no -s, no *to*):

***insist, demand, require, recommend, suggest, propose, request, ask*** + *that* + subject + **base**
***it is essential / vital / important / necessary / advisable that*** + subject + **base**

- *We recommend that she **apply** before Friday.* (not *applies*)
- *It is essential that the report **be** submitted today.* (not *is*)
- *The board insisted that he **not** attend.* (negative = *not* + base)

British English also uses *should*: *We recommend that she **should apply**.*

## 2. Wish and if only

| Situation | Form | Example |
| --- | --- | --- |
| **Present regret** (unreal) | wish + **past** | *I wish I **had** more time.* · *I wish I **were** taller.* |
| **Past regret** | wish + **had + participle** | *I wish I **had accepted** the offer.* |
| **Complaint / wish for change** | wish + **would** | *I wish he **would** answer emails.* |
| **if only** (stronger) | same construction | *If only we **had known**.* |

## 3. would rather, it is (high) time, as if / as though

| Structure | Form | Example |
| --- | --- | --- |
| **would rather** + different subject | + **past** | *I would rather you **sent** it today.* |
| **would rather** + same subject | + **base** | *I would rather **wait**.* |
| **It is (high) time** | + **past** | *It is time we **reviewed** the budget.* |
| **as if / as though** (unreal) | + **past** (were) | *He acts as if he **were** the director.* |
| **suppose / supposing** | + past / present | *Suppose we **lost** the contract?* |

## 4. Formal hypothetical forms

- ***were to***: *If the market **were to** collapse, we would adapt.* (unlikely hypothesis)
- ***should***: *If you **should** need…* (unlikely hypothesis)
- ***but for***: ***But for** your help, we would have failed.* (= without)
- ***otherwise***: *Sign now; **otherwise** the offer expires.*

## Traps for French speakers

- **No -s in the subjunctive**: *He insists that she **go*** (not *goes*).
- **No future or conditional after wish**: *I wish it **were** easier* (not *would be* for a state).
- **were for every subject** in careful style: *If I **were** you*, *as if he **were***.
- **Do not confuse**: *I wish you **would** help* (complaint) ≠ *I hope you **will** help* (real hope).
