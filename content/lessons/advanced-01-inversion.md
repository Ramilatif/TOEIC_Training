# L'inversion et la mise en relief

En anglais soutenu (rapports, discours, lettres formelles), on place parfois un **mot négatif ou restrictif en tête de phrase**. L'auxiliaire passe alors **avant le sujet**, comme dans une question.

## 1. Adverbes négatifs ou restrictifs en tête de phrase

| Début de phrase | Structure | Exemple |
| --- | --- | --- |
| **Never / Rarely / Seldom** | + auxiliaire + sujet + participe | *Never **have we seen** such growth.* |
| **Hardly / Scarcely … when** | + *had* + sujet + participe … *when* + prétérit | *Hardly **had** the meeting **begun** when the power failed.* |
| **No sooner … than** | + *had* + sujet + participe … *than* | *No sooner **had** he **left** than the phone rang.* |
| **Not only … but also** | + auxiliaire + sujet | *Not only **did they miss** the deadline, they also exceeded the budget.* |
| **Only after / Only when / Only then** | + auxiliaire + sujet | *Only after the audit **did we discover** the error.* |
| **Under no circumstances / On no account** | + modal + sujet | *Under no circumstances **should staff** open this file.* |
| **Little** (= ne… pas du tout) | + auxiliaire + sujet | *Little **did he know** that the deal was off.* |

## 2. Inversion à la place de *if* (style très formel)

| Avec *if* | Avec inversion |
| --- | --- |
| *If you **should** need help…* | ***Should you** need help…* |
| *If we **had known**…* | ***Had we known**…* |
| *If I **were** you…* | ***Were I** you…* |

## 3. Autres inversions fréquentes

- **So + adjectif … that** : ***So urgent was** the request that we replied at once.*
- **Such + be … that** : ***Such was** the demand that stocks ran out.*
- **Neither / Nor + auxiliaire + sujet** : *The report was late, **nor did** it contain the figures.*
- **So/Neither do I** : *She agrees. **So do I**.* / *He did not attend. **Neither did I**.*

## Comment fabriquer l'inversion ?

1. Repérer le mot négatif / restrictif en tête.
2. Si le verbe n'a pas d'auxiliaire, **ajouter *do / does / did*** : *Rarely **does** he **arrive** late.*
3. Le verbe lexical repasse à la **forme de base** (*did we discover*, pas *did we discovered*).
4. Après *be*, on inverse sans *do* : ***Never was** the situation so serious.*

## Pièges

- **Pas d'inversion** après *Not only* si la proposition est coordonnée sans reprise : *Not only was the price high, **but** the quality was poor.* (inversion dans le 1er membre seulement).
- **Pas d'inversion** quand le mot négatif ne commence pas la phrase : *We **never** received it.*
- **Double négation interdite** : *Rarely **do** we **not** see…* est lourd et à éviter.
- Au TOEIC, l'inversion est surtout testée en **Part 5-6** : repérez l'ordre *auxiliaire + sujet*.

# Inversion for emphasis

In formal English (reports, speeches, formal letters) a **negative or restrictive word is sometimes placed at the start of the sentence**. The auxiliary then goes **before the subject**, as in a question.

## 1. Negative or restrictive adverbs at the start

| Opening | Structure | Example |
| --- | --- | --- |
| **Never / Rarely / Seldom** | + auxiliary + subject + participle | *Never **have we seen** such growth.* |
| **Hardly / Scarcely … when** | + *had* + subject + participle … *when* + past | *Hardly **had** the meeting **begun** when the power failed.* |
| **No sooner … than** | + *had* + subject + participle … *than* | *No sooner **had** he **left** than the phone rang.* |
| **Not only … but also** | + auxiliary + subject | *Not only **did they miss** the deadline, they also exceeded the budget.* |
| **Only after / Only when / Only then** | + auxiliary + subject | *Only after the audit **did we discover** the error.* |
| **Under no circumstances / On no account** | + modal + subject | *Under no circumstances **should staff** open this file.* |
| **Little** (= not at all) | + auxiliary + subject | *Little **did he know** that the deal was off.* |

## 2. Inversion instead of *if* (very formal)

| With *if* | With inversion |
| --- | --- |
| *If you **should** need help…* | ***Should you** need help…* |
| *If we **had known**…* | ***Had we known**…* |
| *If I **were** you…* | ***Were I** you…* |

## 3. Other common inversions

- **So + adjective … that**: ***So urgent was** the request that we replied at once.*
- **Such + be … that**: ***Such was** the demand that stocks ran out.*
- **Neither / Nor + auxiliary + subject**: *The report was late, **nor did** it contain the figures.*
- **So/Neither do I**: *She agrees. **So do I**.* / *He did not attend. **Neither did I**.*

## How to build the inversion

1. Spot the negative / restrictive word at the start.
2. If the verb has no auxiliary, **add *do / does / did***: *Rarely **does** he **arrive** late.*
3. The main verb goes back to the **base form** (*did we discover*, not *did we discovered*).
4. After *be*, invert without *do*: ***Never was** the situation so serious.*

## Traps

- **No inversion** when the negative word is not at the start: *We **never** received it.*
- **Double negatives are heavy**: *Rarely **do** we **not** see…* should be avoided.
- On the TOEIC, inversion is mostly tested in **Parts 5-6**: look for the *auxiliary + subject* order.
