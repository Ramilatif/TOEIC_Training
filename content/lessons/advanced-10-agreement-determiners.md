# Accord complexe et déterminants avancés

## 1. Noms collectifs et quantifieurs

| Expression | Accord | Exemple |
| --- | --- | --- |
| **a number of** + pluriel | pluriel | *A number of clients **have** complained.* |
| **the number of** + pluriel | singulier | *The number of clients **has** doubled.* |
| **a variety / range / selection of** + pluriel | pluriel | *A range of options **is** / **are** available.* |
| **the majority of** + pluriel | pluriel | *The majority of staff **agree**.* |
| **the majority of** + non dénombrable | singulier | *The majority of the work **is** done.* |
| **a great deal of / a large amount of** + non dénombrable | singulier | *A great deal of time **was** lost.* |
| **none of** + pluriel | singulier (formel) ou pluriel | *None of the files **was** / **were** lost.* |
| **either / neither of** + pluriel | singulier (formel) | *Neither of the options **is** ideal.* |
| **one of** + pluriel | singulier | *One of our clients **has** left.* |
| **each / every** + singulier | singulier | *Every employee **has** a badge.* |

## 2. Sujets coordonnés

- **A and B** → pluriel : *Marketing and sales **work** together.*
- **A or B / either A or B / neither A nor B** → accord avec le **sujet le plus proche** : *Neither the manager nor the **assistants are** present.*
- **A as well as B / A together with B** → accord avec **A** : *The CEO, **as well as** her team, **is** attending.*
- **Deux éléments formant un tout** → singulier : *Fish and chips **is** a classic.*

## 3. Noms d'origine latine ou grecque

| Singulier | Pluriel | Remarque |
| --- | --- | --- |
| datum | **data** | *data* est souvent utilisé au singulier en usage courant |
| criterion | **criteria** | *The criteria **are** clear.* |
| phenomenon | **phenomena** | |
| medium | **media** | *The media **are** / **is**…* |
| analysis | **analyses** | |
| crisis | **crises** | |

## 4. Noms toujours singuliers ou toujours pluriels

- **Non dénombrables** : *advice, information, news, equipment, furniture, research, progress, feedback, luggage*.
- **Toujours pluriels** : *clothes, goods, premises, savings, earnings, surroundings*.
- **Singulier à sens pluriel** : *police, staff, team, committee* (le verbe peut être pluriel en anglais britannique).
- **Matières en -ics** : *economics, mathematics, statistics* (science : singulier ; chiffres : pluriel).

## 5. L'article avec un adjectif

*the + adjectif* désigne un groupe : ***the unemployed** need support*, ***the wealthy** pay more tax* (pluriel, sans nom).

## Pièges

- **« The number of » ≠ « A number of »** : l'article change l'accord.
- **« The premises » est pluriel** : *The premises **are** closed.*
- **« Staff » est collectif** : *Our staff **is** / **are** well trained.* mais *a staff member*.
- **« Data »** : en Part 5 on le trouve avec *are* ou *is* : suivez le contexte et privilégiez le formel *are* si les deux sont proposés.

# Complex agreement and advanced determiners

## 1. Collective nouns and quantifiers

| Expression | Agreement | Example |
| --- | --- | --- |
| **a number of** + plural | plural | *A number of clients **have** complained.* |
| **the number of** + plural | singular | *The number of clients **has** doubled.* |
| **a variety / range / selection of** + plural | plural | *A range of options **is** / **are** available.* |
| **the majority of** + plural | plural | *The majority of staff **agree**.* |
| **the majority of** + uncountable | singular | *The majority of the work **is** done.* |
| **a great deal of / a large amount of** + uncountable | singular | *A great deal of time **was** lost.* |
| **none of** + plural | singular (formal) or plural | *None of the files **was** / **were** lost.* |
| **either / neither of** + plural | singular (formal) | *Neither of the options **is** ideal.* |
| **one of** + plural | singular | *One of our clients **has** left.* |
| **each / every** + singular | singular | *Every employee **has** a badge.* |

## 2. Joined subjects

- **A and B** → plural: *Marketing and sales **work** together.*
- **A or B / either A or B / neither A nor B** → agree with the **nearest subject**: *Neither the manager nor the **assistants are** present.*
- **A as well as B / A together with B** → agree with **A**: *The CEO, **as well as** her team, **is** attending.*
- **Two items forming one whole** → singular: *Fish and chips **is** a classic.*

## 3. Nouns of Latin or Greek origin

| Singular | Plural | Note |
| --- | --- | --- |
| datum | **data** | *data* is often used as singular in everyday use |
| criterion | **criteria** | *The criteria **are** clear.* |
| phenomenon | **phenomena** | |
| medium | **media** | *The media **are** / **is**…* |
| analysis | **analyses** | |
| crisis | **crises** | |

## 4. Always-singular or always-plural nouns

- **Uncountable**: *advice, information, news, equipment, furniture, research, progress, feedback, luggage*.
- **Always plural**: *clothes, goods, premises, savings, earnings, surroundings*.
- **Singular with plural sense**: *police, staff, team, committee* (the verb can be plural in British English).
- **Subjects in -ics**: *economics, mathematics, statistics* (the science: singular; figures: plural).

## 5. The article with an adjective

*the + adjective* denotes a group: ***the unemployed** need support*, ***the wealthy** pay more tax* (plural, no noun).

## Traps

- **"The number of" ≠ "A number of"**: the article changes the agreement.
- **"The premises" is plural**: *The premises **are** closed.*
- **"Staff" is collective**: *Our staff **is** / **are** well trained.* but *a staff member*.
- **"Data"**: in Part 5 it appears with *are* or *is*: follow the context and prefer formal *are* if both are offered.
