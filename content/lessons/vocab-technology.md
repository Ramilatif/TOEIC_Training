| Mot | Traduction | Exemple |

| **upgrade** | mise à niveau | An upgrade is available. |
| **install** | installer | Install the update today. |
| **password** | mot de passe | Change your password. |
| **backup** | sauvegarde | Make a backup daily. |
| **network** | réseau | The network is down. |
| **troubleshoot** | dépanner | IT will troubleshoot it. |
| **log in** | se connecter | Log in with your ID. |
| **download** | télécharger | Download the file. |
| **firewall** | pare-feu | The firewall blocked it. |

- **out of order** : en panne
- **technical support** : assistance technique
- **keep up with** : se tenir au courant
- **state-of-the-art** : de pointe
- **cloud storage** : stockage en ligne

<!-- lang:en -->
# Vocabulary: technology

Software, networks, backups: IT vocabulary shows up in many texts.

## Key words

| Word | Meaning | Example |
| --- | --- | --- |
| **software** | computer programs | Update your software. |
| **upgrade** | a newer, better version | An upgrade is available. |
| **install** | to put software on a computer | Install the update today. |
| **password** | a secret word for access | Change your password. |
| **backup** | a copy of data | Make a backup daily. |
| **network** | linked computers | The network is down. |
| **troubleshoot** | to find and fix a problem | IT will troubleshoot it. |
| **log in** | to enter a system | Log in with your ID. |
| **download** | to copy files from the internet | Download the file. |
| **firewall** | security that blocks unwanted access | The firewall blocked it. |
| **malfunction** | failure to work properly | A printer malfunction. |
| **compatible** | able to work together | Is it compatible with our system? |

## Useful collocations and expressions

- **out of order**
- **technical support**
- **keep up with**
- **state-of-the-art**
- **cloud storage**

## TOEIC tip

'Out of order' and 'not working' are common paraphrases: in Part 3 they refer to a breakdown.

Add these words to your flashcards to review them with spaced repetition.
