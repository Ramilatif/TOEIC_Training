# Les quantificateurs

Le choix dépend de la nature du nom : **dénombrable** (pluriel) ou **indénombrable**.

## Tableau

| Avec nom dénombrable (pluriel) | Avec nom indénombrable | Avec les deux |
| --- | --- | --- |
| many | much | a lot of / lots of |
| (a) few / fewer | (a) little / less | plenty of |
| a number of | a great deal of / a large amount of | some / any / no |
| several / both / various | — | most / all / enough |

*How many* employees ? / *How much* money ?

## Sens à bien distinguer

- **a few / a little** = quelques, un peu (positif) ; **few / little** = presque pas (négatif).
- **fewer** (dénombrable) / **less** (indénombrable) : *fewer mistakes, less time*.
- **some** (affirmatif, offre) / **any** (négatif, interrogatif, *if*).
- **most of the** + nom défini / **most** + nom général : *most employees*, *most of the employees*.

## Pièges

1. **Much** s'emploie surtout en phrase négative ou interrogative ; en affirmatif, préférez *a lot of*.
2. **Each / every / either / neither** → singulier.
3. **All / both** + *of the* : *all of the files*.
4. **A number of** (pluriel) ≠ **the number of** (singulier).

<!-- extra -->
## Pièges des francophones

- **many / few / a few** + dénombrable pluriel ; **much / little / a little** + non dénombrable. *many employees, much information*.
- **few / little** = presque pas (négatif) ; **a few / a little** = quelques (positif).
- **a lot of / lots of** : informel mais admis dans les deux cas.
- **Each / every / any / all** : *each* + singulier, *all* + pluriel ou non dénombrable, *any* surtout en négation et question.
- **Pas de « of » devant un nom sans déterminant** : *most **employees*** mais *most **of the** employees*.

## Exemples en contexte

- *We received **few** applications, so we extended the deadline.*
- *There is **little** time left before the deadline.*

# Quantifiers

The choice depends on the noun: **countable** (plural) or **uncountable**.

## Table

| With countable (plural) nouns | With uncountable nouns | With both |
| --- | --- | --- |
| many | much | a lot of / lots of |
| (a) few / fewer | (a) little / less | plenty of |
| a number of | a great deal of / a large amount of | some / any / no |
| several / both / various | — | most / all / enough |

*How many* employees? / *How much* money?

## Meanings to tell apart

- **a few / a little** = some (positive); **few / little** = hardly any (negative).
- **fewer** (countable) / **less** (uncountable): *fewer mistakes, less time*.
- **some** (affirmative, offers) / **any** (negative, questions, *if*).
- **most of the** + definite noun / **most** + general noun: *most employees*, *most of the employees*.

## Traps

1. **Much** is mostly for negatives and questions; in affirmatives prefer *a lot of*.
2. **Each / every / either / neither** → singular.
3. **All / both** + *of the*: *all of the files*.
4. **A number of** (plural) ≠ **the number of** (singular).

## Traps for French speakers

- **many / few / a few** + countable plural; **much / little / a little** + uncountable. *many employees, much information*.
- **few / little** = hardly any (negative); **a few / a little** = some (positive).
- **a lot of / lots of**: informal but fine with both.
- **Each / every / any / all**: *each* + singular, *all* + plural or uncountable, *any* mostly in negatives and questions.
- **No "of" before a noun without a determiner**: *most **employees*** but *most **of the** employees*.

## Examples in context

- *We received **few** applications, so we extended the deadline.*
- *There is **little** time left before the deadline.*
