# Modaux avancés et atténuation (hedging)

Au niveau C1, les modaux servent à **nuancer** : degrés de certitude, reproche discret, politesse, atténuation.

## 1. Les degrés de certitude

| Degré | Expressions | Exemple |
| --- | --- | --- |
| **Certain (≈ 95 %)** | must, can't / couldn't, be bound to, be sure to | *Prices **are bound to** rise.* · *He **can't** have left.* |
| **Probable** | should, ought to, be likely to | *The shipment **should** arrive today.* |
| **Possible** | may, might, could, be liable to | *It **may** rain.* · *The pipes **are liable to** freeze.* |
| **Improbable** | might (just), be unlikely to | *We **might just** make the deadline.* |

## 2. Modal + have + participe passé (le passé)

| Forme | Sens | Exemple |
| --- | --- | --- |
| **must have** | déduction quasi certaine | *They **must have received** it.* |
| **can't / couldn't have** | impossible | *She **can't have known**.* |
| **may / might / could have** | possible mais incertain | *He **might have forgotten**.* |
| **should / ought to have** | reproche, regret | *You **should have called**.* |
| **needn't have** | action faite inutilement | *You **needn't have rushed**: the deadline was Friday.* |
| **would have** | irréel | *I **would have helped**.* |

**needn't have ≠ didn't need to** : *I **needn't have brought** the files* (je les ai apportés pour rien) / *I **didn't need to bring** the files* (je n'étais pas obligé, peut-être ne l'ai-je pas fait).

## 3. Atténuer pour rester professionnel (hedging)

| Technique | Exemple |
| --- | --- |
| Verbes d'atténuation | *The results **appear to** / **seem to** / **tend to** suggest…* |
| Modaux | *This **could** / **might** indicate a problem.* |
| Adverbes | *It is **possibly** / **arguably** the best option.* |
| Formules | *It would **appear** that… · To a certain extent… · In some cases…* |
| Conditionnel de politesse | ***Would** you mind…? · I **was wondering** whether…* |

## 4. Autres emplois à connaître

- ***would*** pour les habitudes passées : *Every summer we **would** visit the plant.*
- ***used to*** : *We **used to** print everything* (état ou habitude révolue).
- ***dare*** : *I **dare not** ask.* (rare, formel)
- ***be to*** : *The CEO **is to** announce the merger tomorrow.* (planification officielle)

## Pièges des francophones

- **Pas de *must* au passé** : on dit *had to* (obligation) ou *must have* (déduction).
- **should have ≠ must have** : reproche ≠ déduction.
- **Un seul modal** : *will can* est faux → *will be able to*.

# Advanced modals and hedging

At C1 level, modals are used to **nuance**: degrees of certainty, tactful criticism, politeness, softening.

## 1. Degrees of certainty

| Degree | Expressions | Example |
| --- | --- | --- |
| **Certain (≈ 95 %)** | must, can't / couldn't, be bound to, be sure to | *Prices **are bound to** rise.* · *He **can't** have left.* |
| **Probable** | should, ought to, be likely to | *The shipment **should** arrive today.* |
| **Possible** | may, might, could, be liable to | *It **may** rain.* · *The pipes **are liable to** freeze.* |
| **Unlikely** | might (just), be unlikely to | *We **might just** make the deadline.* |

## 2. Modal + have + past participle (the past)

| Form | Meaning | Example |
| --- | --- | --- |
| **must have** | almost certain deduction | *They **must have received** it.* |
| **can't / couldn't have** | impossible | *She **can't have known**.* |
| **may / might / could have** | possible but uncertain | *He **might have forgotten**.* |
| **should / ought to have** | criticism, regret | *You **should have called**.* |
| **needn't have** | done unnecessarily | *You **needn't have rushed**: the deadline was Friday.* |
| **would have** | unreal | *I **would have helped**.* |

**needn't have ≠ didn't need to**: *I **needn't have brought** the files* (I brought them for nothing) / *I **didn't need to bring** the files* (I was not obliged; maybe I did not).

## 3. Hedging to stay professional

| Technique | Example |
| --- | --- |
| Hedging verbs | *The results **appear to** / **seem to** / **tend to** suggest…* |
| Modals | *This **could** / **might** indicate a problem.* |
| Adverbs | *It is **possibly** / **arguably** the best option.* |
| Phrases | *It would **appear** that… · To a certain extent… · In some cases…* |
| Polite conditional | ***Would** you mind…? · I **was wondering** whether…* |

## 4. Other uses to know

- ***would*** for past habits: *Every summer we **would** visit the plant.*
- ***used to***: *We **used to** print everything* (past state or habit).
- ***dare***: *I **dare not** ask.* (rare, formal)
- ***be to***: *The CEO **is to** announce the merger tomorrow.* (official planning)

## Traps for French speakers

- **No *must* in the past**: use *had to* (obligation) or *must have* (deduction).
- **should have ≠ must have**: criticism ≠ deduction.
- **Only one modal**: *will can* is wrong → *will be able to*.
